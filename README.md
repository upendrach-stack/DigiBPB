# DigiBPB — BPB Offshore Digital Dashboard

Digital dashboard for **BPB Offshore Platform, NH&BS Asset, Mumbai Offshore** under Oil and Natural Gas Corporation Ltd.

A modern, single-page web application providing quick access to critical offshore operational resources.

## Features

- ONGC corporate branding with dark navy/teal gradient theme
- KPI cards for quick access to operational documents
- Daily Helicopter Schedule download
- Responsive design for desktop and mobile
- Configurable download URLs via simple JavaScript config

## Live Dashboard

```
https://upendrach-stack.github.io/DigiBPB/
```

## Tech Stack

- HTML5 / CSS3 / Vanilla JavaScript (no dependencies)
- GitHub Pages hosting
- Python sync script for automated file updates
